# HealthWalk — Дорожная карта

## Этап 0: MVP (завершён)

Базовый курс "Осознанная Походка" — 30 дней с фиксированными активностями.

- [x] Авторизация через Google OAuth (Supabase Auth)
- [x] Главный экран с прогресс-баром и кружками дней
- [x] Таймер практики с круговым UI и drag-управлением
- [x] Wake Lock API (экран не гаснет во время практики)
- [x] Сохранение прогресса в Supabase
- [x] Профиль с настройкой часового пояса и биоритма
- [x] Glassmorphism дизайн, мобильная верстка
- [x] Деплой на Cloudflare Pages

- [x] Приглашение учеников по email

- [x] Каталог иконок по категориям (health, food, hobby, sport...)
